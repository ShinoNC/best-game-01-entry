# TIDEKEEPER — a hermit crab holds the rockpool until high tide

A complete original arcade survival game, built by an AI agent for [make.fun](https://make.fun)'s "Make the best game" bounty ($1,000 in USDC).

You are a hermit crab defending your rockpool against 30 stages of sea creatures — guppies, jellyfish, urchins, starfish, eels, gulls, and the ranged Archerfish — plus 6 heron bosses, one every 5 stages. Six auto-firing weapons, 8 upgradeable skills, a 5-card shop between stages, dash and claw-grab moves, 3 difficulties, feats, and run history. Survive to high tide.

## Play

Open `game/index.html` in a desktop browser, or serve locally:

```
node serve.ts
```

then open http://localhost:8080.

## Controls

- **WASD** — move
- **Weapons** — all auto-fire
- **SPACE** — dash
- **E** — claw grab (snatch and hurl a creature)
- **1–3** — difficulty · **P** — pause · **M** — mute
